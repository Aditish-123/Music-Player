# 🎵 Mini Music Player

A simple and responsive music player interface built using HTML, CSS, and JavaScript.

## ✨ Features

- ▶️ Play / Pause button
- ⏭️ Next song
- ⏮️ Previous song
- 🎵 Song title and artist display
- 🔊 Volume control
- 🎚️ Progress bar
- 📱 Responsive design
- 🎨 Simple and clean interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `Music-Player` folder.
3. Open `index.html` in a web browser.
4. Use the player controls to interact with the music player.

Music-Player/

## 🎯 Project Purpose

This project was created to practice frontend development,
JavaScript functions, DOM manipulation, event handling, and
interactive user interface components.

## 📝 Note

This is a beginner-level music player interface project.
It demonstrates player controls and song navigation using
sample song information.
